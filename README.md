# FinanceFlow

FinanceFlow is a Personal Finance Management System built with Java Spring Boot.

## Tech Stack

- Java 21
- Spring Boot 3
- PostgreSQL
- Spring Data JPA
- Flyway
- Validation
- Lombok
- MapStruct
- Swagger/OpenAPI

## Features

- User Management
- Bank Account Management
- Transaction Management
- CSV Import
- Auto Categorization Rules
- Dashboard & Reports

## Database

- PostgreSQL
- Flyway Migration
